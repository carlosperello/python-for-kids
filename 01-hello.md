# Exercise 1 — Hello, world!

**You will learn:** `print`, strings, comments, and the REPL (a secret calculator).

## 1. Your first program

Type exactly this (capital letters and quotes matter!):

```python
print("Hello, world!")
```

Press **Run**. Mu will ask to save the file — save it as `hello.py`.
Look at the bottom panel: that's Python speaking!

## 2. Make it yours

The words between the quotes are called a **string**. Python prints exactly
what's between the quotes — nothing more, nothing less.

Change the string so it says hello to *you* by name, and run again.

## 3. Say more

Lines that start with `#` are **comments** — Python ignores them. They are
notes for humans (like the sticky-note comments in Scratch):

```python
# my first program
print("Hi, I'm Alex")
print("I am 12")
print("I like building things")
```

## 4. ASCII art — drawing with text

You can draw with letters and symbols. This is called ASCII art:

```python
print("  ^ ^  ")
print(" ( o o )")
print("   ---")
```

Make your own: a face, a flag, a robot, a spaceship.

## 5. The secret calculator

Click the **REPL** button. A panel opens at the bottom with a `>>>` prompt.
It's a calculator that is always ready:

```
>>> 2 + 2
4
>>> 12 * 12
144
>>> 7 / 2
3.5
```

Try: how old are you in days? (age × 365). How many seconds is that?

## Challenges

- Make Python tell a joke in three lines: the setup, an empty `print()` for
  dramatic pause, then the punchline.
- Print a fake conversation between two people (use strings for both parts).
- Break it on purpose: remove one quote and run. Read the error. Now you know
  what a `SyntaxError` looks like — make it friends with you, you'll meet it a lot.

## What you know now

- `print(...)` shows text on the screen
- Text between quotes is a **string**
- `#` starts a comment, a note for humans
- The REPL is a calculator for quick experiments
